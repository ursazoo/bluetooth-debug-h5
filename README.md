# BLE LAB · 蓝牙调试台

无依赖的单文件 Web Bluetooth 调试页，用于 BLE GATT 设备。

## 使用

1. 在支持 Web Bluetooth 的浏览器中通过 HTTPS 打开页面，手机建议 Android Chrome。iPhone Safari 不支持此 API。
2. 开启系统蓝牙和设备电源，点击“查找附近设备”，在浏览器弹出的列表中选择设备。
3. 在“查看连接结果”中确认是否连接成功。只测试连接时不需要填写技术参数。
4. 如需读写数据，展开“高级调试”，填写厂商提供的 Service UUID（不是 Characteristic UUID），重新查找设备并授权，再按厂商协议操作。

页面不提供音箱文字播报。普通蓝牙音箱通过手机系统配对后播放音频，不能直接把 BLE 数据写入当作音频播放。

不填 UUID 时默认申请电池、设备信息、心率三个标准服务。支持 HEX 和 UTF-8 写入、断连重连、JSON 日志导出。蓝牙通信及日志均在浏览器本地处理，不发送到服务器；导出日志可能包含设备标识及通信内容。

## 部署

GitHub Pages 从 `main` 分支根目录发布 `index.html`，无需构建步骤。

## 验证范围

已检查移动端布局，以及模拟 BLE 设备的连接、读写、通知、断连重连和输入校验。简化界面另验证了高级参数默认折叠、中文操作提示，以及“已连接但无法读取服务”的状态区分。真实蓝牙兼容性需在目标手机和设备上验证。
