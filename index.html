使用条件与常见问题
  • 使用 HTTPS 部署；电脑本机 localhost 可用于开发，手机访问电脑的普通 HTTP 局域网地址不可以。
  • Android Chrome 可测试；iPhone Safari 不支持 Web Bluetooth。
  • 仅适用于 BLE GATT 设备，不能直接控制经典蓝牙 SPP 设备。
  • 服务 UUID 与特征 UUID 不同。新增服务授权后，请重新“选择并连接设备”。
  • 所有设备模式仍由浏览器决定可见列表，不是无限制扫描仪。按服务筛选要求设备在广播中包含该服务。
  • 不知道设备协议时，先查看和读取；写入数据请以设备协议为准。
